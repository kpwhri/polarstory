# Variable metadata API

Define research-friendly labels, semantic variable types, category orders, and sensitive-value handling.

Most users only need [`Variables.set()`](variables-set.md) to customize metadata.

| API | Description |
| --- | --- |
| [`Variables`](variables.md) | Column metadata; selectors are expanded against a specific source schema |
| [`Variable`](variable.md) | API definition and return type |
| [`Variables.set`](variables-set.md) | Add a reusable semantic-metadata rule for selected variables |
| [`Variables.resolve`](variables-resolve.md) | Resolve configured metadata rules against an input schema |
