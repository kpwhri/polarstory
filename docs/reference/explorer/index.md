# Variable exploration API

Preview individual variables and grouped descriptive results in VS Code notebooks or from Python scripts.

| API | Description |
| --- | --- |
| [`explore`](explore.md) | Convenience entry point for VS Code Jupyter/Interactive sessions |
| [`Explorer`](explorer.md) | Select, preview and collect single-variable exploratory summaries |
| [`Explorer.preview`](explorer-preview.md) | Get bounded reusable results for a variable and optional stratum |
| [`Explorer.add_to_report`](explorer-add_to_report.md) | Add the current analysis and its exact settings to the report |
| [`Explorer.show`](explorer-show.md) | Display optional ipywidgets controls in a notebook |
